تشغيل دار السلام على Vercel مع قاعدة Neon المجانية
====================================================

هذه نسخة Vercel فعلية: ملفات الواجهة في جذر المشروع، ومسارات API داخل مجلد api، والبيانات تُحفظ في PostgreSQL على Neon. لا تستخدم نسخة server.mjs وحدها على Vercel؛ ملف الخادم المحلي لا يعمل كـ Vercel Function.

الخطة المجانية مناسبة للتجربة ببيانات وهمية فقط. Vercel Hobby مخصص للاستخدام الشخصي غير التجاري، وقاعدة Neon المجانية لها حدود استخدام وقد تنام عند عدم الاستخدام. لا تحفظ بيانات حضور حقيقية أو بيانات شخصية خلال التجربة.

1) إعداد Neon
- أنشئ حساب Neon واختر الخطة Free عند إنشاء المشروع وقاعدة البيانات.
- من لوحة Neon انسخ connection string الخاصة بقاعدة البيانات، واحتفظ بها سرًا. لا تضعها في ملفات الواجهة أو GitHub.
- يحتاج التطبيق فقط إلى DATABASE_URL؛ سيُنشئ جدول البيانات تلقائيًا عند أول طلب API.

2) رفع ملفات التطبيق
- ارفع محتويات هذا المجلد إلى مستودع GitHub، مع مجلد api وملف package.json.
- لا ترفع data.json أو أي نسخة احتياطية أو ملف يحتوي أسرارًا.
- اربط مستودع GitHub بمشروع Vercel الحالي، أو أنشئ مشروعًا جديدًا من المستودع. عند تحديث المشروع الحالي، أبقِ اتصال Git والمجال نفسه كي يبقى رابط dar-alsalam-app.vercel.app.

3) إعداد Vercel Environment Variables
في مشروع Vercel افتح Settings > Environment Variables وأضف القيم التالية لبيئة Production. بعد إضافتها اضغط Save ثم أعد نشر أحدث نسخة Production:

DATABASE_URL = connection string من Neon
AUTH_SECRET = قيمة عشوائية طويلة لا تقل عن ٣٢ حرفًا
INITIAL_ADMIN_USERNAME = admin
INITIAL_ADMIN_NAME = مشرف دار السلام
INITIAL_ADMIN_PASSWORD = كلمة مرور أولية قوية للمشرف
ADMIN_RECOVERY_CODE = رمز استعادة طويل وفريد لا يقل عن ١٦ حرفًا

اكتب الأسرار في Vercel فقط، ولا تضعها في المحادثة أو في GitHub. اختر قيمتي AUTH_SECRET وADMIN_RECOVERY_CODE بنفسك واحفظهما في مكان آمن.

4) النشر والدخول
- انتظر اكتمال نشر Vercel وظهور الحالة Ready.
- افتح رابط التطبيق وسجّل الدخول باسم المستخدم admin وكلمة المرور الأولية التي وضعتها في INITIAL_ADMIN_PASSWORD.
- سيطلب التطبيق تغيير كلمة المرور في أول دخول.
- إذا نسيتها، استخدم زر «نسيت كلمة مرور المشرف؟» مع ADMIN_RECOVERY_CODE.

5) تجربة الوظائف
- أنشئ موظفًا تجريبيًا، ثم جرّب الدخول بحسابه وإضافة مهمة وإعلان وتسجيل حضور وانصراف.
- من «التقارير» نزّل نسخة احتياطية دوريًا. لا تعتمد على خدمة مجانية كنسخة احتياطية.

ملاحظات مهمة
- لا تستخدم هذه الحزمة مع إعدادات Render Blueprint إلا عند نشر نسخة server.mjs على Render.
- إذا لم تتوفر DATABASE_URL أو AUTH_SECRET، سيرجع API رسالة إعداد واضحة.
- Vercel Hobby ليس خطة للاستخدام التجاري؛ قبل تشغيل بيانات عمل الحضانة الحقيقية راجع شروط الخطة واستخدم استضافة وقاعدة بيانات تسمح بهذا الاستخدام.
